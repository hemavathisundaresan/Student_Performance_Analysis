# Student Performance Analysis

## Project Overview
This project uses Exploratory Data Analysis (EDA) to explore student mathematics performance and identify patterns in final grades.

## Objectives
- Analyze student performance using Python.
- Explore the relationship between study time and final grades.
- Examine the effects of absences and past failures on grades.
- Visualize patterns in student data.

## Dataset
- **Source:** UCI Student Performance Dataset
- **Records:** 395 students
- **Features:** 33 columns
- **Target variable:** `G3` (final mathematics grade)

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Workflow
1. Load and inspect the dataset.
2. Check missing values and duplicate records.
3. Perform exploratory data analysis.
4. Compare grades across different student characteristics.
5. Create visualizations to communicate findings.

## Key Findings
- The average final mathematics grade was approximately 10.42 out of 20.
- The median final grade was 11.
- Grades varied across study-time groups and past-failure categories.
- The findings describe associations and do not establish causation.

## Project Files
- `Student_Performance_Analysis.ipynb` — analysis and visualizations.
- `student-mat.csv` — dataset.
- `Student_Performance_Analysis.pdf` — project report.

## Conclusion
This project demonstrates practical skills in data analysis, exploratory data analysis, data visualization, and interpreting patterns in student performance.
